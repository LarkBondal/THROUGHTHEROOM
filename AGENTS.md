# Adding a page

Use the viewport meta tag from `index.html` and load the shared `styles.css`.
Wrap each page in `.site-page` for a full-width layout that fills the viewport
and grows with its content. Use page-specific classes for artwork and layout.
Reuse the shared top controls and drawer with `script.js` where the page
includes site navigation.

Keep key artwork proportional, respect device safe areas, and preserve the
shared controls' placement and appearance. Check each new page at laptop,
narrow portrait phone, and landscape phone sizes. Verify that content remains
reachable, there is no horizontal scrolling, and the drawer works when present.
